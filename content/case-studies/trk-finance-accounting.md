# TRK Finance & Accounting Systems
Backend improvements across an existing UK loan management platform and an accounting application.

## The systems
The loan platform covers investor funds, loan disbursements, interest calculations, repayments, and document verification. The accounting application supports day-to-day financial operations.

## My contribution
- **Database and API optimization:** Reviewed existing queries, removed unnecessary database calls and loops, and improved processing efficiency across application workflows.
- **Backend refactoring:** Refactored existing backend code and introduced reusable helper functions to reduce duplication, simplify complex operations and improve maintainability.
- **API security and validation:** Improved route security and request validation for backend endpoints.
- **Production stability:** Investigated backend issues, refined error handling and optimized existing workflows for production use.

## Engineering focus
This work centered on improving systems already in use: understanding their current behavior, finding avoidable work in database and API paths, then making changes that improved efficiency, security, and maintainability.
