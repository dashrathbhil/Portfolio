# Dashrath Bhil Portfolio

A concise portfolio for backend engineering work across energy pricing, debt collection, finance, accounting, and workplace IT.

## Portfolio structure

- **Homepage:** A short profile, technical skills, experience, and four selected projects.
- **Case studies:** Longer project context and engineering detail stored in Markdown under content/case-studies and rendered at /case-studies.
- **Screenshots:** A few representative product screens; the IT asset project uses a workflow graphic because no project screenshot is included in the current assets.

## Featured projects

- **AMSL Broker Portal** — supplier price-book processing, tariff calculations, quotations, contracts, and commissions.
- **AUC — All Utilities Collection** — account allocation, field visits, live updates, and collection reporting.
- **TRK Finance & Accounting Systems** — loan and accounting applications, query optimization, API security, and backend refactoring.
- **IT Asset Management** — PowerShell device inventory, QR lookup, and a web application for asset records.

## Technologies

Next.js, TypeScript, React, Tailwind CSS, Nodemailer, and Brevo SMTP.

## Local development

Install dependencies with npm install, then run npm run dev.

Create a production build with npm run build and start it with npm start.
